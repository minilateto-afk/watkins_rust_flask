研究方法 / 第二階段

先確立資料與統計品質，再逐步驗證能否使用病害進展模型或推論統計。

DATA PIPELINE

資料處理流程

  1. 保留原始 Excel 及三列來源標題。
  2. 記錄病害、地點、苗期／成株期、觀測日期與來源欄。
  3. 將明確百分比（如 50MR）拆為 50 與 MR。
  4. 標記 TMS、0-20MSS、DRY 等需進一步解釋的紀錄。
  5. 僅以可解析的數值計算描述統計，並公開缺失狀況。
FORMULAS

統計方法

平均數： x̄ = Σxᵢ / n

樣本標準差： s = √[Σ(xᵢ − x̄)² / (n − 1)]

中位數與四分位數：使用排序及分位數的描述性定義。

若排除痕量或區間資料，其平均值只代表明確解析的子集合，不能宣稱無偏代表全體材料。

PHASE 2 / IMPLEMENTED

AUDPC 梯形法（已實作）

針對原始 Excel 的 I / J / K 欄，限定 2013 年 KARI-Njoro 成株期黃銹病 4/21、4/30、5/7，同一材料三次都具有明確嚴重度，才計算：

AUDPC = [(y₁ + y₂)/2] × 9 + [(y₂ + y₃)/2] × 7

輸出單位為 %·天。另計算 AUDPC / 16 天，解讀成時間加權平均嚴重度（%）。這是依相鄰觀測點之間採線性近似的數值積分，不是實際連續病程的精確積分。

例：Excel 第 2 號材料 4/21、4/30、5/7 的數值分別為 20%、30%、30%，AUDPC = (20 + 30)/2 × 9 + (30 + 30)/2 × 7 = 435 %·天。對應時間加權平均 435/16 = 27.1875%。

本版採完整案例（490/650），排除另外 160 份記錄，不插補。缺失不是隨機時可能造成偏差。不同地點或不同觀測期不混合計算。

數學參考：American Phytopathological Society (APS), AUDPC。

NOT YET IMPLEMENTED

暫緩的方法

  • Spearman：跨地點觀測條件、樣本配對與比較尺度需要再核對，現在未使用。
  • Friedman：重複量測獨立性與研究設計前提尚未確認，現在未使用。
  • 遺傳率、基因定位、正式育種排名：來源資料不支持這些推論。
