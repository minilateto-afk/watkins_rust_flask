# 第一階段：資料清理、描述統計與數學核對

## 1. 研究資料

- 原始資料為 Watkins 小麥 2013 年銹病表型觀測 Excel，採自公開研究資料紀錄（Zenodo DOI 10.5281/zenodo.8349020）。
- 工作表 `Summary of SCPRID Phenotypes`：3 行標題、650 筆材料，含 29 個有記錄的量測欄位（黃銹病、莖銹病、葉銹病；成株期與幼苗期分開處理）。
- 本專題使用既有資料，沒有自行在田間進行測量。

## 2. 程式清理後的資料概況（全體 650 × 29 = 18,850 個觀測格）

| 種類 | 筆數 | 處理方法 |
|---|---:|---|
| 成株期明確嚴重度（例如 `50MR`） | 8,932 | 轉為 0–100 嚴重度數字，保留感染反應 |
| 幼苗期明確數字（例如 `3`） | 1,830 | 保存為幼苗分數，不當成嚴重度百分比 |
| `-`、`---`、`;` 等缺失標記 | 7,202 | 不補 0 |
| 痕量（例如 `TMS`） | 483 | 保留 raw，不換算 0 |
| 區間（例如 `0-20MSS`） | 278 | 保留 raw，不擅自取中點 |
| 特殊標記（例如 `DRY`、`SUSC`） | 93 | 保留 raw |
| 空白 | 20 | 缺失，不補 0 |
| 未明確可解析的文字（例如 `Sr26`） | 12 | 保留 raw |

**關鍵：** 8,932 筆是「可明確解讀的成株病害嚴重度記錄」，不是 8,932 個獨立小麥品種。不同日期可能是同一材料的重複測量。所有平均數均只描述該日期的可解析資料子集。

## 3. 計算方法與手算核對

本階段只採用：平均數、樣本標準差、中位數、四分位數、分布圖與資料完整度。

### 示例：Njoro 黃銹病 2013/04/21（來源 Excel 的 I 欄）

來源前五筆材料的原始紀錄：`50MR`、`20MR`、`20MR`、`30S`、`30MR`。

明確數值部分可分離為：

x₁=50, x₂=20, x₃=20, x₄=30, x₅=30

平均數：

x̄ = (50+20+20+30+30)/5 = 150/5 = 30 (%)

樣本變異數：

s² = [(50−30)²+(20−30)²+(20−30)²+(30−30)²+(30−30)²]/(5−1)

= (400+100+100+0+0)/4 = 150

樣本標準差：

s = √150 ≈ 12.247 (%)

**這是為了驗證公式而抽出的五筆觀測值，不能拿這五筆代表全部材料。** 整欄資料由 Python 計算。

### 實際完整欄位的描述性結果

| 資料欄 | 日期 | 可解析筆數 | 平均嚴重度 | 中位數 | 樣本標準差 |
|---|---|---:|---:|---:|---:|
| I | 4/21 | 496 | 31.341% | 30% | 18.691% |
| J | 4/30 | 490 | 38.735% | 40% | 18.856% |
| K | 5/7 | 490 | 44.827% | 50% | 20.706% |

這個表只顯示不同日期**當日可解析子樣本**的描述統計。若要分析「同一材料隨時間變化」，必須配對同一批完整材料，不能直接把表中三個平均數的差異解讀為病害增長的統計證據。

## 4. 使用 Python 和 Flask 的分工

1. 數學：先理解統計量，選五筆範例手算核對。
2. `prepare_data.py`：匯入原始 Excel，保留原始評分並輸出長格式與品質紀錄。
3. `app.py`：由 Pandas 對選定日期的有效數字計算平均、標準差及分位數。
4. Plotly：把數字繪成可互動直方圖、品質圖與材料觀測圖。
5. Flask：負責資料篩選、網頁操作與 CSV 下載。

## 5. 下一階段待確認，不在第一版計算

- AUDPC：確認哪些日期是同一田間系列、評分量尺可靠，對完整材料進行梯形法累積病害評估。
- Spearman：確認跨地點材料的對應與可比較性後再計算。
- Friedman：確認配對結構及檢定前提後再考慮加入。
- 目前不執行感染反應權重（CI）、一般品種 ANOVA、遺傳率、QTL 或抗病基因相關分析。
