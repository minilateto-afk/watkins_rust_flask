# 第二階段｜小麥黃銹病 AUDPC 的數學推導、來源與驗證

## 1. 為什麼進行這項分析？

研究對象是 Watkins 小麥資料中的 **2013 年肯亞 KARI-Njoro 成株期黃銹病、4/21、4/30、5/7** 三個連續觀測時間點。這是 Excel 同一標題區塊下的 **I、J、K 欄**。本研究把病害嚴重度視為在各時間點的離散數據，透過梯形法估計這段期間的曲線下面積（AUDPC），而非嘗試找到病原基因或進行育種試驗。

資料來源：Watkins Yellow Rust Phenotypes Kenya & Ethiopia，Zenodo，DOI：10.5281/zenodo.8349020。

方法參考：American Phytopathological Society（APS），*Calculating the area under the disease progress curve to quantify disease progress*：
https://www.apsnet.org/edcenter/sites/EcologyAndEpidemiologyInR/DiseaseProgress/Pages/AUDPC.aspx

## 2. 從梯形法推導

令 yᵢ 為第 i 次觀測的病害嚴重度（%），tᵢ 為距第一次觀測的天數。以直線連接相鄰觀測點，該區間的面積近似為一個梯形：

Aᵢ = [(yᵢ + yᵢ₊₁)/2] × (tᵢ₊₁ − tᵢ)

因此：

AUDPC = Σᵢ Aᵢ = Σᵢ [(yᵢ + yᵢ₊₁)/2] × (tᵢ₊₁ − tᵢ)

單位是 **%·天**。這是由離散觀測所作的梯形近似，**不代表真實連續病程一定是分段線性**。

本資料中：

- t₁ = 0（4/21）
- t₂ = 9（4/30）
- t₃ = 16（5/7）

故 AUDPC = [(y₁ + y₂)/2] × 9 + [(y₂ + y₃)/2] × 7。

時間加權平均嚴重度 = AUDPC / (t₃ − t₁) = AUDPC / 16，單位為 %。它不是感染機率，不是品種遺傳率，也不是對病害的正式抗性分級。

## 3. 以 Excel 中真實材料手算

Excel 第 2 號材料（材料 accession 1190202，名稱 Manitoba velloso，來源國 Spain）原始評分：

| 原始欄 | 日期 | 原始文字 | 擷取嚴重度 |
|---|---|---|---:|
| I | 4/21 | 20MR | 20% |
| J | 4/30 | 30MR | 30% |
| K | 5/7 | 30MR | 30% |

注意 MR 是感染反應標記；本階段 AUDPC 僅計算可解析之「嚴重度」百分比，沒有將 MR 另行加權。

第一段：A₁ = [(20 + 30)/2] × (9 − 0) = 25 × 9 = 225 %·天。

第二段：A₂ = [(30 + 30)/2] × (16 − 9) = 30 × 7 = 210 %·天。

總 AUDPC = 225 + 210 = **435 %·天**。

時間加權平均嚴重度 = 435/16 = **27.1875%**。

Python 的 `audpc_analysis.py` 先根據上述公式逐段計算，再透過測試檔與 NumPy `trapezoid` 核對結果。

## 4. 完整資料篩選規則

- 只採原始 Excel I、J、K 這三個觀測欄；不跨接 Sep–Oct 的 L、M 欄，也不跨接其他地點。
- 同一份材料必須在三欄都有明確、數值落在 0–100 的成株期百分比評分，例如 `20MR`、`30S`、`0`。
- 缺失 (`-`)、痕量 (`TMS`)、區間 (`0-20MSS`)、特殊標記 (`DRY`) 不視為 0，也不擅自使用平均或內插。
- 原始評分字串、Excel 行列號及排除原因都保留，以便逐筆檢查。

| 項目 | 結果 |
|---|---:|
| 原始材料筆數 | 650 |
| I 欄有效數值 | 496 |
| J 欄有效數值 | 490 |
| K 欄有效數值 | 490 |
| 三欄都完整、可計算 AUDPC | 490 |
| 未納入 AUDPC | 160 |
| 完整材料 AUDPC 中位數 | 630 %·天 |
| 完整材料 AUDPC 平均數 | 約 608.52 %·天 |
| 完整材料 AUDPC 最小、最大值 | 0、1270 %·天 |

**這 490 筆資料形成的是「完整案例子集」**，不保證能無偏代表其餘 160 筆材料。若缺失與病害情況有關，分布可能存在選擇偏差。

## 5. 程式究竟做什麼？

1. `prepare_data.py` 從原始 Excel 提取 29 個測量欄並保留來源字串。
2. `audpc_analysis.py` 驗證 I/J/K 對應的日期、地點、病害與系列；篩選完整三點；逐筆計算兩段梯形面積、總 AUDPC 和時間加權平均。
3. 將合格結果輸出到 `data/processed/audpc_njoro_apr_may.csv`，未合格結果及理由輸出到 `data/processed/audpc_excluded.csv`，摘要另存 `audpc_summary.json`。
4. `app.py` 使用 Flask 與 Plotly 提供 AUDPC 分布、任一材料的三點曲線、逐段計算表、搜尋與 CSV 下載。
5. `tests/test_audpc.py` 驗證實際材料 2 的手算結果、完整與排除材料數、零病害/固定嚴重度、輸入驗證、錯誤系列、重複資料、NumPy 比對等。

這是「數學公式先理解、用少量真實資料手算，再由 Python 自動批次計算，最後由 Flask 呈現」，不是先畫漂亮的圖再反推分析結果。

## 6. 研究限制與下一階段

- AUDPC 是**同一地點、同一時段**可解析嚴重度的累積指標。不能直接說最小 AUDPC 的材料有抗病基因，或保證其他年度與地點仍低病害。
- 未取得完整田間重複區塊與統計試驗設計，現階段不做品種 ANOVA、遺傳率估計及抗性成因的因果推論。
- 本階段沒有進行 Friedman 或 Spearman 檢定；未經充分核對觀測配對與資料尺度前先暫緩。
- 原始 Excel 的資料再散布權限仍須依 Zenodo 授權檢查。不要在未確認授權前將原始 Excel、衍生逐筆 CSV 或整個 Docker 映像公開發布。
