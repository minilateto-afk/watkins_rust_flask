METHODOLOGY / LIMITATIONS

研究方法 / 第一階段

先確立資料與統計品質，再逐步驗證能否使用病害進展模型或推論統計。

DATA PIPELINE

資料處理流程

  1. 保留原始 Excel 及三列來源標題。
  2. 記錄病害、地點、苗期／成株期、觀測日期與來源欄。
  3. 將明確百分比（如 50MR）拆為 50 與 MR。
  4. 標記 TMS、0-20MSS、DRY 等需進一步解釋的紀錄。
  5. 僅以可解析的數值計算描述統計，並公開缺失狀況。
FORMULAS

統計方法

平均數： x̄ = Σxᵢ / n

樣本標準差： s = √[Σ(xᵢ − x̄)² / (n − 1)]

中位數與四分位數：使用排序及分位數的描述性定義。

若排除痕量或區間資料，其平均值只代表明確解析的子集合，不能宣稱無偏代表全體材料。

NEXT STAGE / NOT YET IMPLEMENTED

下一階段候選方法

  • AUDPC：檢查每組日期是否屬同一場連續觀測、評分與缺失規則，再使用梯形法。
  • Spearman：先確認不同地點可以可靠配對同一材料，且比較期間與病害具可比性。
  • Friedman：需要先確認重複測量的配對關係與推論前提。

本版未計算上述三種方法，也未推斷抗病基因、遺傳率或正式育種選拔結果。
